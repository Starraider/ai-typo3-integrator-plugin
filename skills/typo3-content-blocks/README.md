# TYPO3 Content Blocks

This Skill covers creating, editing, and debugging Content Blocks supplied by `friendsoftypo3/content-blocks`.

## Use it for

- Content element, page type, record type, file type, or shared-field blocks
- `config.yaml` fields, labels, templates, previews, icons, and generated TCA
- discovery, schema, rendering, or validation failures

## Included material

`SKILL.md` contains the workflow, canonical directory layout, configuration examples, and troubleshooting guidance. The Skill is self-contained and has no executable scripts or MCP dependency.

## Working approach

Start by finding the loaded site package and existing `ContentBlocks/` conventions. Confirm the extension and TYPO3 setup, then make the smallest change that follows those conventions. Run the project’s normal Content Blocks linting or schema validation after editing.

Read [SKILL.md](SKILL.md) for the full instructions and examples.
